# AcceptBox

Первый предварительный выпуск помогает зафиксировать версию набора проверок EBT
и проверить совместимость установленного WitnessBox.

Установка предварительной версии:

```sh
uv tool install acceptbox==0.1.0a1
```

Чтобы собрать wheel и исходный архив, выполни `uv build` в каталоге с
`pyproject.toml` пакета.

Чтобы зафиксировать набор проверок, передайте путь или URL репозитория и полный
SHA коммита. Команда читает дерево `ebt/` из объектов Git и печатает 64 символа
SHA-256. Для неё нужен Git.

```sh
acceptbox pin --ebt-repo /path/to/project --ebt-sha "$(git -C /path/to/project rev-parse HEAD)"
```

Отпечаток учитывает пути, типы и режимы записей, а также содержимое файлов.
Для символической ссылки учитывается записанный в Git путь, для подмодуля —
идентификатор его коммита. Незакоммиченные правки и файлы вне `ebt/` на отпечаток
не влияют.

Команда `acceptbox --installation` выводит JSON с версией AcceptBox, путём и версией
WitnessBox из `PATH`. Поддерживаются выпуски WitnessBox 0.9.x. Код 0 означает
совместимую установку, код 2 — отсутствие команды, несовместимую версию или сбой
диагностики.

Вердикт приёмки и отчёт `accept.json` запланированы на полный выпуск 0.1.0.
